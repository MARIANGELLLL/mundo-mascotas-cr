# 🐾 Mundo Mascotas CR

## Proyecto Web

Mundo Mascotas CR es una tienda virtual desarrollada como proyecto académico de Desarrollo de Páginas Web.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages

## Características

✅ Diseño responsive  
✅ Navegación entre páginas  
✅ Catálogo de productos  
✅ Servicios para mascotas  
✅ Formulario de contacto  
✅ Animaciones CSS  
✅ Validaciones con JavaScript  
✅ Despliegue automático con GitHub Pages
